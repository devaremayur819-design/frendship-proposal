# 💖 Interactive Friendship Proposal Website

A premium, viral-ready, interactive web experience created using standard HTML5, CSS3, and modern Vanilla JavaScript. Features glassmorphic UI cards, sound effects, dynamic canvas-based animations, interactive evade mechanics, and automatic friendship certificate rendering!

---

## ✨ Features

- **Luxury Aesthetics**: Dynamic ambient mesh gradient, blur glassmorphism, floating particle engine, and crisp typography (`Poppins` + `Playfair Display`).
- **Interactive "NO" Evasion**: Dynamic button physics engine featuring scale-downs, teleports, quote changes, secret counters, and a finale explosion.
- **Dynamic Audio FX**: Sound synthesis fallback context ensuring rich interaction feedback across any browser or network condition.
- **Automated Certificate Engine**: Dynamic HTML5 Canvas rendering for automatic PNG friendship certificate downloads.
- **Hidden Achievements**: Interactive mini-games and event triggers (e.g., puppy clicker, evasion tracking).
- **Zero External Dependencies**: Pure native JavaScript with zero framework overhead running smoothly at 60–120 FPS.
